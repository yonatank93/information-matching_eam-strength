# Developing EAM potential for plastic strength via information-mathcing method

This repo contains the scripts and data about the development of EAM potential for
plastic strength predictions via the information-matching method for active learning.



## Specific requirements

* Orchestrator (LLNL)
* [information-matching](https://github.com/yonatank93/information-matching)
* [QUESTS](https://github.com/dskoda/quests/tree/main)



## Content

* *eam-snap* - Containing scripts and data for the cases fitted to EAM and SNAP proxy
  ground truth. These 2 cases are combined into a single folder because they use the same
  dataset.
* *dft* - Containing scripts and data for the case fitted to DFT ground truth.
