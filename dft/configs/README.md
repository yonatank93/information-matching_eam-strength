# Candidate atomic configurations

**Note:** The extxyz file needs to be downloaded separately.

## Main content

* *DS_t3jry72ii4xi_0.extxyz* - Atomic configurations with DFT ground truth data
  that Amit shared.
* *postprocess_amit_dataset.py* - Python script to post-process the shared
  configurations.

## How to use

```bash
$ python postprocess_amit_dataset.py
```
